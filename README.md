# 芒学 mángxué（まんしゅぇ）

二次創作と勉強を両立するための、オフラインで使える学習・制作アプリです。
推し活やファンコミュニティで暮らしながら、資格の勉強も続けたい人のために作りました。

- 毎日やることを、勉強と原稿の両方から1画面に並べます。
- 自分の問題集を一問一答で解けます。出題は本の順番どおりで、周回ごとに記録します。
- 勉強と原稿の進み具合を％で表示します。
- Xには、何かやっているのが伝わる程度の控えめな文面でシェアできます。
- 電車の圏外でも使えます。スマホ・タブレット・PCのあいだで記録を自動同期します。

## しくみ

このリポジトリには、アプリの仕組みだけが入っています。個人の予定・問題・記録は入っていません。

| 置き場所 | 中身 | 公開 |
|---|---|---|
| このリポジトリ（GitHub Pages） | アプリ本体 | 公開 |
| 自分の非公開リポジトリ | `plan.json`（計画）、`questions/`（問題）、`devices/`（各端末の記録） | **必ず非公開** |

アプリは、自分で発行したトークンを使って非公開リポジトリと直接やりとりします。トークンや記録が、ほかのサーバーに送られることはありません。

## 使いはじめる

1. 非公開リポジトリを作ります（例：`mangxue-data`）。
2. `examples/plan-example.json` をコピーし、`plan.json` という名前で非公開リポジトリの一番上に置いて書き換えます。
3. GitHub で fine-grained token を発行します。対象はそのリポジトリだけにし、権限は Contents の Read and write だけにします。
4. アプリを開き、メニューの「同期・Googleカレンダー・バックアップ」で、持ち主・リポジトリ名・トークンを入力します。
5. 2台目からは、「ほかの端末に設定を移す」のQRコードかリンクを使います。トークンが入っているので、人には見せないでください。
6. ホーム画面に追加すると、アプリとして開けます。

## Googleカレンダーと連携する（任意）

Googleカレンダーの予定を「プライベートの予定」として取り込み、計画の節目・期日をGoogleに書き出せます。
どちらも、ボタンを押したときだけ動きます。Googleのアカウントごとに、自分で無料の登録をします。

1. Google Cloud Console（console.cloud.google.com）で、新しいプロジェクトを作ります。
2. 「APIライブラリ」で Google Calendar API を有効にします。
3. 「Google Auth Platform」のはじめての設定（Get Started）で、アプリ名・サポート用のメール・ユーザーの種類「外部（External）」・連絡先のメールを入力して作成します。
4. 「対象（Audience）」のテストユーザー（Test users）に、自分のGoogleアカウントを追加します。公開の手続きはいりません。
5. 「データアクセス（Data Access）」で、次のスコープを追加します。
   - `calendar.calendarlist.readonly`（カレンダーの一覧を見る）
   - `calendar.events.readonly`（予定を見る）
   - `calendar.app.created`（アプリが作った「制作と学習の計画【芒学】」カレンダーだけに書く）
6. 「クライアント」→「クライアントを作成」で、種類「ウェブ アプリケーション」を選び、「承認済みの JavaScript 生成元」にアプリのアドレスを入力します（例：`https://ユーザー名.github.io`。アプリの「同期・Googleカレンダー・バックアップ」画面にあるGoogleカレンダーの「？」に、入力するアドレスが出ます）。
7. できたクライアントID（`…apps.googleusercontent.com`）を、アプリの「同期・Googleカレンダー・バックアップ」画面に貼り付けます。

- クライアントIDは公開されても困らない番号です。一緒に出る**クライアントシークレットは使いません**。どこにも貼らないでください。
- ログインのとき「このアプリは確認されていません」と出ますが、自分で登録したものなので、そのまま進めます。
- ログインはアプリを開いている間だけ（1時間ほど）有効です。アプリはログインの情報を保存しません。
- Googleの画面の表記は、更新で変わることがあります。かっこ内は英語表示のときの名前です。

## plan.json の書き方

| 項目 | 内容 |
|---|---|
| `start` | 計画を始める日 |
| `study.exam` | 試験日と名前（ホームのカウントダウン） |
| `study.units` | 科目や章と、それぞれの期間（`id`・`name`・`short`・`start`・`end`） |
| `study.phases` | 科目のない期間に表示する名前（例：直前期） |
| `study.books` / `idPrefix` / `idPad` / `blankBooks` | 問題集の名前・問題IDの頭につける文字・番号の桁数・空欄補充形式の本 |
| `study.baseBook` | 解説画面で「紙の本を開く」として表示する基本書の名前 |
| `create.event` | イベントの日付と名前 |
| `create.works` | 作品（ページ数、表紙の有無、プロット工程の有無） |
| `create.stages` | 工程と重み（例：ネーム .15、下書き .25 …） |
| `create.focus` | 時期ごとの原稿の中心（平日・休日）。`until` の日まで有効です |
| `create.hoursPerPage` / `coverHours` / `plotHours` / `due` | ％の見積もりに使う時間と入稿日 |
| `schedule` | 期間ごとの時間割（`weekday`・`sat`・`sun`）。タイトルには `{unit}`・`{focus.weekday}`・`{focus.weekend}`・`{focus.note}`・`{lastWeekNote}` を使えます |
| `milestones` | `[日付, 内容]` の一覧 |
| `batches` / `workdays` | 問題の取り込み日と作業日 |

勉強の中身は差し替えられます。資格試験でも、語学でも、学校の勉強でも使えます。
